# Evidence and confidence

Historical sources can be incomplete, stale, or contradictory. Current code establishes behavior; recorded explanations establish intent.

- **Direct:** a source explicitly states the reason. Cite it and state the claim plainly.
- **Supported:** several records support a conclusion indirectly. Show the evidence and the inference.
- **Inferred:** a plausible interpretation with limited support. Label it and explain the reasoning.
- **Speculative:** a possible explanation with little evidence. Include it only when it helps resolve the question.
- **Unknown:** the available evidence does not establish the answer. Name the relevant gap.

These distinctions guide wording, not mandatory output sections. Do not inflate certainty to make prose smoother or add doubt where direct evidence is clear.

Preserve contradictions. Treat a user's suggested reason as a hypothesis. An unsuccessful search does not establish that a discussion never happened. Report meaningful search limits without listing every unused system.
